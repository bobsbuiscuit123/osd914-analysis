# OSD914-Analysis: Hepatic-Neuro Cross-Talk AI

### Project Overview
This repository contains the multi-modal AI pipeline for analyzing systemic transcriptomic signaling between hepatic (liver) and neuro-inflammatory (brain) profiles in spaceflight models, specifically focused on **NASA OSDR Study OSD-914 (GLDS-736)**.

### Archive
Zenodo archives are updated from tagged GitHub releases for this repository. The concept DOI is https://doi.org/10.5281/zenodo.21283918; release-specific DOI records should be cited when exact frozen artifacts are required.

### Project Phases
1. **Phase I: Data Harmonization:** API extraction and subject-matching for 686 multi-tissue samples.
2. **Phase II: Model Architecture:** MLP implementation for predictive signaling modeling.
3. **Phase III: Explainability:** SHAP/LIME integration for feature importance.
4. **Phase IV: Validation:** KEGG/GO pathway mapping.
